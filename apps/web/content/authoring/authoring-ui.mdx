---
title: Author with Kyoshi
description: Build a course with Kyoshi, the authoring agent – then trial and evaluate its lessons.
---

Kyoshi is the authoring agent. It drafts lessons with you in the authoring UI, as ordinary
course files you can edit anywhere.

## Start a course

In an empty folder:

```sh
npx dojofoo kyoshi --style katas --name my-course
```

It scaffolds a kata course (`katas` is the only style so far) and opens the authoring UI.
`--name` defaults to the folder's name. To reopen it later, from the course folder:

```sh
npx dojofoo ui --authoring
```

## Build a lesson

Tell Kyoshi who the course is for, what they already know and what they should be able to do
afterwards. Build one small lesson and refine it before the next.

The sidebar lists the course's files and lessons, and the editor takes your changes. Review
every exercise, test and note yourself: Kyoshi drafts, you know the subject.

## Trial and evaluate

- **Trial** a lesson to take it as a learner, with the agent you pick for the trial.
- **Evaluate lesson** has one model teach the lesson to another playing the learner, and two
  judges review the session. Choose the models in **Evaluation settings**. It uses your model
  quota, runs once the lesson's checklist is complete, and allows three attempts for the same
  lessons.

An evaluation is evidence to read, not a guarantee. Rework the lesson when the sensei skips a
prerequisite, gives the answer away or leaves a stuck learner stuck.

## From the command line

| Command | Does |
| --- | --- |
| `npx dojofoo kyoshi` | Scaffold the course if needed and open the authoring UI |
| `npx dojofoo kyoshi inspect` | Print the course's files, lessons and readiness as JSON |
| `npx dojofoo kyoshi lesson <title>` | Add a lesson scaffold |
| `npx dojofoo kyoshi setup` | Run the course's mise `setup` task |
| `npx dojofoo kyoshi check` | Run the course's mise `check` task |
| `npx dojofoo kyoshi evaluate <lesson> [next]` | Evaluate one lesson, or a lesson and the one after it |

`kyoshi` also takes the `ui` options `--background`, `--no-open`, `--no-portless`, `--port`
and `--tld`.
