The authoring UI edits the same files you'd edit by hand; there's no separate publishing format.

## What's in a course

A kata course, laid out like the [starter](https://github.com/dojofoo/starter-kata):

```text
my-course/
├── dojo.yaml                  the manifest: name, test command, katas
├── DOJO.md                    teaching notes for the whole course
├── mise.toml                  tools and the setup task
├── package.json
└── katas/
    └── 001-first-kata/
        ├── solution.ts        what the learner starts from
        ├── solution.test.ts   what checks their work
        └── SENSEI.md          teaching notes for this kata
```

Interactive courses swap `katas/` for guided lesson steps – see
[interactive lessons](/authoring/interactive).

## Two ways to build one

- [Create a course](/authoring/manual) – start from the starter and edit in your editor.
- [Author with Kyoshi](/authoring/authoring-ui) – build lessons with the authoring agent, then
  trial and evaluate them.

Either way, start with one lesson: what the learner should understand, an exercise, its tests
and its notes. Try it as a learner before you write the next.
