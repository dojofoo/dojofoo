## Install

<InstallCommand />

Verify the CLI:

```sh
npx dojofoo --help
```

## Requirements

- Node.js 20 or newer.
- A coding agent that can read project files and run shell commands —
  [Claude Code](https://docs.anthropic.com/claude/docs/claude-code) is the
  default target.
- For language-specific dojos, the matching toolchain (e.g. `pnpm` for
  TypeScript dojos, `uv` for Python dojos).

The CLI runs through `npx`, so there is no global package to uninstall. Remove
an installed dojo from a project with `npx dojofoo remove <name>`.
