<Callout type="warn">
  `/kata` is deprecated: not every course is made of katas. Learn with
  [`npx dojofoo ui`](/docs/commands/ui) instead. Projects set up before keep the command for now.
</Callout>

`/kata` is a command you type in your agent, not in the shell. `npx dojofoo install` adds it,
along with `/dojo`.

```text
/kata
```

## What happens

1. The agent starts the [lesson UI](/docs/commands/ui) in the background and reads where you
   are: no course yet, the course's introduction, a kata's briefing, or practice.
2. It teaches from the course's notes for that step – asking questions and giving hints, not
   solutions.
3. When you're ready, it runs the kata's tests. When they pass, the kata is complete and you
   choose: review it, move on to the next one, or pause.
4. Before it stops, it notes what it learned about how you work, so the next session builds on
   it.

Progress lives in the project. Run `/kata` again any time to pick up where you left off.

## /dojo

`/dojo` passes its arguments to the CLI, for anything else:

```text
/dojo --list               list the installed courses
/dojo --change effect-ts   switch the active course
```

## The CLI underneath

The agent drives these; you can run them yourself too.

| Command | Does |
| --- | --- |
| `npx dojofoo status` | Show where you are in the course |
| `npx dojofoo kata` | Print the current kata's teaching notes |
| `npx dojofoo kata intro` | Show the current kata's briefing |
| `npx dojofoo kata --check` | Run the current kata's tests |
| `npx dojofoo kata --start` | Set up the next kata |
| `npx dojofoo kata --list` | List the katas and their state |
| `npx dojofoo kata --change <name>` | Switch to a kata and set it up |
| `npx dojofoo kata --note "text"` | Record an observation about the learner |
