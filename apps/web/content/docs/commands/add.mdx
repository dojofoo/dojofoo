---
title: add
description: Install a course from GitHub, the catalog, a URL or a local folder.
---

```sh
npx dojofoo add <source> [--force] [--master] [--yes] [--agent <a,b>]
```

## Sources

| Source | Example |
| --- | --- |
| GitHub repository | `npx dojofoo add dojofoo/effect-ts` |
| Catalog name | `npx dojofoo add effect-ts` |
| Tarball URL | `npx dojofoo add https://example.com/course.tgz` |
| Local folder | `npx dojofoo add ../my-course` |

## Options

| Option | Description |
| --- | --- |
| `--force` | Replace a course that's already installed |
| `--master` | Install an editable copy with its authoring files, to build on it. Respect the course's license. |
| `--yes` | Install a course with security warnings without asking. A failed check still stops the install. |
| `--agent <a,b>` | Also set up these agents, as [install](/docs/commands/install) does |

## What it does

- Copies the course to `courses/<name>/`. For a remote source it records where the course came
  from, and its content hash, in `courses/<name>/.dojo-source.json`.
- Makes it the active course and links any agent commands and skills it ships into your agents'
  folders.
- Prepares its environment: `mise install` and its `setup` task when it has a `mise.toml`,
  otherwise its JavaScript dependencies when it has a `package.json`; and its `prepare.sh`, if it
  has one.
- Sets up the first kata, unless a kata is already active.

`add` sets up the project as `install` does if you haven't, but only connects agents it can
detect or that you name with `--agent`.

Before installing a GitHub course, `add` reads its
[security checks](/docs/marketplace#security-checks): a failed check stops the install, and a
warning asks first. The first install of a public GitHub course reports it to the
[marketplace](/docs/marketplace), unless its manifest sets `private: true`.
