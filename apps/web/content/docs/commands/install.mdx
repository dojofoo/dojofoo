---
title: install
description: Set up a project and its coding agents for dojofoo.
---

```sh
npx dojofoo install [--claude] [--opencode] [--codex] [--agy] [--pi]
```

Run it once in the folder you open in your agent. `setup` is an alias.

## Options

| Option | Description |
| --- | --- |
| `--claude` | Set up Claude Code |
| `--opencode` | Set up OpenCode |
| `--codex` | Set up Codex |
| `--agy` | Set up Antigravity |
| `--pi` | Set up Pi |
| `--agent <a,b>` | The same, as a list: `--agent claude,codex` |
| `--skills` | Only refresh the dojofoo skill for the agents already set up |

Without an option, `install` detects the agent it runs in. Outside an agent it asks, offering
OpenCode, Codex and Pi.

## Examples

```sh
npx dojofoo install                      # detect, or ask
npx dojofoo install --claude             # choose
npx dojofoo install --agent opencode,pi  # several at once
```

## What it does

- Adds mise for your user when it's missing (not with `--skills`).
- Creates `.dojo/config.yaml` and the `courses/` folder.
- Writes the [deprecated](/docs/commands/kata) `/kata` and `/dojo` commands to
  `.agents/commands/` and links them into each agent's folder, e.g. `.claude/commands/`.
- Writes the dojofoo skill to `.agents/skills/dojofoo/SKILL.md`.
- For Claude Code, adds permissions to `.claude/settings.json` so the agent may run `npx dojofoo`
  without asking. Your own settings and permission rules stay as they are.

It's safe to run again, e.g. to add another agent. Commands you've edited in `.agents/commands/`
are kept; the skill is refreshed.

<Callout type="warn">
  If `.claude/settings.json` isn't valid JSON, `install` leaves it as it is and warns, without
  adding the permissions.
</Callout>
