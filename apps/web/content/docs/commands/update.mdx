---
title: update
description: Update an installed course from where it came from.
---

```sh
npx dojofoo update <name|owner/repository>
```

## Examples

```sh
npx dojofoo update effect-ts
npx dojofoo update dojofoo/effect-ts
```

## What it does

Fetches the course again from the source recorded when you added it. When nothing changed, it
says the course is up to date; otherwise it replaces `courses/<name>/`.

Your solutions in `katas/` and your progress are kept. If you've edited files inside
`courses/<name>/`, `update` stops rather than overwrite them.
