---
title: Quickstart
description: From an empty folder to your first lesson in a few minutes.
---

You need Node.js 24 or newer and a supported coding agent – see
[Installation](/docs/installation).

## 1. Set up the project

In the folder you open in your agent:

```sh
npx dojofoo install
```

It detects the agent you're running, or asks. To choose yourself, pass a flag such as
`--claude` or `--codex` – see [install](/docs/commands/install).

## 2. Add a course

```sh
npx dojofoo add dojofoo/effect-ts
```

The course lands in `courses/effect-ts/`, and any tools it pins are installed with
[mise](/docs/installation#course-environments). Find more courses in the
[marketplace](/docs/marketplace).

## 3. Start learning

```sh
npx dojofoo
```

It opens the lesson UI at `https://dojo.localhost` (or `http://localhost:4567`): the lesson, an
editor, the tests and the sensei side by side. The sensei introduces the course, then the first
lesson, runs the tests and asks about your approach. See [ui](/docs/commands/ui).

<Callout type="info">
  Stuck? Ask for a hint. The sensei narrows the problem down with you instead of writing the
  answer.
</Callout>
