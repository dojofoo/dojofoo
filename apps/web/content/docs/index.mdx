Dojo.foo turns your coding agent into a teacher. You install a course into a project, and the
agent works through it with you as your sensei: it explains, asks questions and runs the tests,
but leaves the code to you.

## How it works

- A **course** (or *dojo*) is a Git repository of lessons. Kata courses are small exercises,
  each with failing tests; interactive courses are guided steps.
- The **sensei** is your agent, following the course's teaching notes. It hints and asks;
  it doesn't hand out solutions.
- Your work and progress stay in your project, as plain files you can commit.

## Start

```sh
npx dojofoo install
npx dojofoo add dojofoo/effect-ts
npx dojofoo
```

Then `npx dojofoo` opens the first lesson in your browser. The [Quickstart](/docs/quickstart)
walks through it.
