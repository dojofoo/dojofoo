## Use the API

The [API](/docs/api) serves the catalog, each course's progress numbers and the
lifecycle events the CLI records. Its read routes follow the skills.sh API, so a skills.sh
client works with `skills` renamed to `courses`.

## Work on dojofoo

The CLI, the lesson and authoring UI, the API and this website live in one repository:
[dojofoo/dojofoo](https://github.com/dojofoo/dojofoo). Its README covers development setup;
open issues and pull requests there.

Want to learn with dojofoo instead? Start with the [Quickstart](/docs/quickstart).
