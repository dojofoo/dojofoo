## Interactive agent ownership checkpoint, 2026-10-27

Interactive courses now supply the shared Composer with the current native coding agent, registered lesson-agent choices, advertised model options and host-owned selection handlers. Pi remains excluded from this ACP learner runtime. The new explicit PUT configuration/harness route validates choices before runtime access, including empty, unsupported and inherited-object-property names. Failed starts/resumes retain the previous binding. Competing selections, turns and model changes cannot overwrite each other; duplicate pending requests for the same agent share one start. The UI retains the question and course material through changes. Request counters also prevent late conversation/model refreshes from replacing a newly selected agent; the browser regression first reproduced the old agent label returning after a switch.

The existing version-1 active conversations entry remains compatible. Additional conversationAgents entries retain native IDs and model choices per course and agent, without copying messages into another store. Legacy single-conversation state is preserved on the first switch. Runtime keys include the harness so a Codex selection cannot reuse an OpenCode process. Interactive default selection now uses the existing lesson runtime configuration precedence, matching kata behavior. Course answers, step position and authored sources are unchanged.

A native gate exposed that Codex does not materialize an unused thread until its first user message. New empty selections therefore carry a pendingRuntime marker. Reading a selection left by an earlier process returns its agent and empty state without starting or resuming a thread. Explicit preparation or the first submitted message can create a fresh empty native thread. Once a message is submitted, the marker is removed before transport; its ID is retained even if the provider then fails, and an uncertain turn is never automatically replayed. Legacy/submitted IDs are never silently replaced. A learner can reselect an unused agent to load its native model choices without submitting the typed question. See the installed codex-acp resumeThread contract and https://github.com/agentclientprotocol/codex-acp/blob/main/src/CodexAcpClient.ts.
