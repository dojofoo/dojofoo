# @dojofoo/build-llm

Build a language model and a reasoning model from scratch through hands-on Python katas.

```sh
npx dojofoo install
npx dojofoo add build-llm
```

Run `/kata` inside your configured agent, or open the course UI:

```sh
npx dojofoo ui
```

Requires Python 3.11+ and [uv](https://docs.astral.sh/uv/). A CPU is sufficient.
