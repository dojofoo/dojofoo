# @dojofoo/pydantic-agents

Learn Pydantic models, validation, and Pydantic AI through hands-on katas.

```sh
npx dojofoo install
npx dojofoo add pydantic-agents
```

Run `/kata` inside your configured agent, or open the course UI:

```sh
npx dojofoo ui
```
