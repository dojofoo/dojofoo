# @dojofoo/effect-ts

Learn Effect through 40 hands-on katas guided by an AI sensei.

```sh
npx dojofoo install
npx dojofoo add effect-ts
```

Run `/kata` inside your configured agent, or open the course UI:

```sh
npx dojofoo ui
```
