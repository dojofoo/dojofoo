In your independent draft, tell Kyoshi your audience, the outcome, and a small example task. A useful request is: “Help me create one lesson about combining default settings with a user's choices. Ask what the learner already knows before drafting it.”

The course manifest describes the course. `DOJO.md` gives course-wide teaching guidance. A lesson's `SENSEI.md` describes how its tutor should help; the exercise and tests describe the work itself. Inspect the files Kyoshi creates rather than assuming a chat reply has saved them.

Keep the first task focused. Explain the expected result and include a small example. Give the Sensei a hint they can offer before showing a solution. Ask Kyoshi to explain any suggested file change.

Save your changes and inspect the draft's readiness feedback. Files that remain incomplete need attention before trial or evaluation.
