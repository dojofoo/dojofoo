Use the **Dashboard** breadcrumb, then choose **New course**. Dojo creates a separate folder for your draft and opens it in Kyoshi authoring.

Your draft appears under **Authoring** on the Dashboard, so you can return to it later. Keep this tutorial open in another tab while you work.

Ask Kyoshi to use the audience and outcome you chose in the previous step. Give your draft its own name and check the files in the editor before continuing.

You can also start from an empty folder in a terminal:

```sh
mkdir my-first-dojo
cd my-first-dojo
npx dojofoo kyoshi --style katas --name my-first-dojo
```

To reopen that draft, run `npx dojofoo ui --authoring` from its folder.
