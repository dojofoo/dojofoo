Open a terminal outside the tutorial's installation folder. Create an empty folder for your own course:

```sh
mkdir my-first-dojo
cd my-first-dojo
npx dojofoo kyoshi --style katas --name my-first-dojo
```

This is the existing authoring command. It scaffolds a kata course in the current folder and opens authoring. Agent setup or a first conversation may require your configured agent and its normal model usage.

Use an empty folder you own. Do not run this command inside `.dojos/create-your-own-dojo` or inside the source of this tutorial. Your draft and this tutorial must have different file roots and names.

Keep the tutorial available in its own workspace while you work. To reopen your draft later, run `npx dojofoo ui --authoring` from the draft folder.

See [Author with Kyoshi](https://dojo.foo/authoring/authoring-ui) for the supported commands.
