Every installed course has one workspace: the folder where its files and progress belong.

When you start `npx dojofoo` in a folder, that folder is the workspace for courses you install. Open a course from Courses to return to its existing workspace. There is no second workspace to select for the same course.

Course files live under `courses/<course-id>`. Saved lesson progress belongs to that workspace. Your account and installation settings live separately in `~/.dojofoo`.

To move a course, remove its installation and install it in the new folder. Keep any work you want before removing it.

The [quickstart](https://dojo.foo/docs/quickstart) explains the initial setup.
