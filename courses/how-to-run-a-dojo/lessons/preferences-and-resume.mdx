Use the content window's settings control for the supported learning preferences. Those preferences belong to how you view learning material; they are separate from course content and authoring evaluation settings.

You can hide or resize the chat where the layout allows it. On a small screen, the conversation opens as a separate panel. If you cannot see a control, first check whether its panel is closed.

Interactive progress and the native Sensei session binding are saved in the selected workspace. Reopen the same course in the same workspace to resume. Another folder is another workspace. An unsent question is not part of the saved conversation; send it only when you want a response.

For help, return to [documentation](https://dojo.foo/docs) or ask the Sensei about the current step. To create a course of your own, start with the draft tutorial “Create your own dojo” and the [authoring guide](https://dojo.foo/authoring/authoring-ui).

Before you leave, note which workspace you used and one question you want to explore next.
