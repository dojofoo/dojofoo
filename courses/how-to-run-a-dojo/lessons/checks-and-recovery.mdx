This orientation uses questions to check your understanding. Submit an answer with Check answer. Feedback appears inside the slide.

If the answer is incorrect, the next slide stays locked. Review the material, ask Sensei for a hint, or try another answer. A correct answer lets you continue.

Your answers and unlocked material are saved in the course workspace. Revisiting a slide does not start a new lesson or discard that progress.

Other courses can include code exercises and test results. Those checks belong to their own lessons; this orientation does not run a kata test suite.
