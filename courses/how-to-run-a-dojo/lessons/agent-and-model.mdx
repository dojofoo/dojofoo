The composer’s Agent menu selects the coding agent that runs Sensei. Its name and logo should match the agent installed on your machine, such as Claude Code or Codex.

The Model menu shows choices reported by that agent. Opening it can prepare the agent’s session without sending your typed question. Selecting a model changes the session’s model; only Send submits your message.

Use the agent’s normal sign-in when authentication is needed. A connection error does not erase your course progress. Resolve the connection or retry it, then continue where you stopped.

Never paste API keys or other secrets into course material or chat. Use the agent’s supported authentication flow.
