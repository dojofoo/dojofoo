Dojofoo uses your configured agent harness. A working agent installation and its normal authentication are needed for an actual Sensei reply. Reading a lesson by itself does not prove that the agent is connected.

The model picker shows choices supplied by the current session. It can remain unavailable before a session exists; a disabled picker is not a promise that a particular model is installed. Change the model only when actual choices are available.

Follow the setup and permission prompts of the agent you selected. Read what an action requests before allowing it. If a connection or authentication error appears, keep your work and resolve that error rather than repeatedly sending the same message.

Never paste API keys or other secrets into course material or chat just to diagnose setup. Use the agent's supported authentication flow.

See [installation](https://dojo.foo/docs/installation) for the supported setup path.
